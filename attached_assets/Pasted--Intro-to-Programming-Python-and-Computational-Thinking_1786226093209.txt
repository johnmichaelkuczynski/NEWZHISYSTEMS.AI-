📚 A Four-Week Journey from Zero to Real Programs
No experience required. Twenty-eight bite-size topics take you from your very first line of Python to shipping a complete working project:

Week 1 — Thinking Like a Programmer — What a program really is · variables and types · expressions · input and output · your first Python script · the art of computational thinking.
Week 2 — Control Flow and Logic — Making decisions in code · loops and repetition · nested logic · reading error messages like a pro · systematic debugging.
Week 3 — Data Structures and Functions — Lists, strings, and dictionaries · elegant Python idioms · writing your own functions · organizing code that scales.
Week 4 — Building Real Programs — Working with files · handling errors gracefully · the standard library · thinking about efficiency · building and shipping a real project.
Every topic comes with lectures at three depths, conversation starters for your tutor, and unlimited adaptive practice.
