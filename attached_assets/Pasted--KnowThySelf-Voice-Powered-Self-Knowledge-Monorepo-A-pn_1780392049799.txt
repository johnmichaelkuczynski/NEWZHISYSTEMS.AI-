🪞 KnowThySelf — Voice-Powered Self-Knowledge (Monorepo) A pnpm workspace housing KnowThySelf, a four-unit, spoken-first self-inquiry course where you answer honest questions out loud and an AI tells you something true about yourself — analysis, not grading.

🧩 What This Is KnowThySelf walks one person through a structured month of self-inquiry. You read a short lesson, sit with a probing prompt, record a spoken answer, and get a candid, perceptive reading of what your answer — and the way you gave it — reveals. Each reading compounds into a cumulative portrait across nine dimensions, culminating in a capstone that names the one conflict you're really trying to resolve.

🗂️ Layout App: artifacts/speak-course — the user-facing course (served at /). API: artifacts/api-server — Express API at /api (DB, object storage, AssemblyAI transcription, OpenAI analysis, diagnostics). Videos: artifacts/speak-course-demo (product demo) and artifacts/speak-course-marketing (promo) — both with audio. Shared libraries: lib/ — OpenAPI spec (source of truth), generated React Query hooks + Zod validators, Drizzle DB schema. Package names, slugs, and speaking_* table prefixes are kept from the project's origins — only the subject, behavior (grade → analyze), and branding changed.

⚙️ How It Works Spoken pipeline: browser records with MediaRecorder → presigned upload → object storage → server transcribes via AssemblyAI → derives delivery metrics → produces a candid reading via OpenAI, then rebuilds the cumulative profile. Analysis, not grading: every answer returns a headline, interpretation, and observations[]; the profile returns dimensions, a synthesis, and — after the capstone — a primaryConflict. No scores. Fail-loud: if transcription or analysis fails, the response is stored failed and the API returns 502 — never a fabricated reading. Contract-first: one OpenAPI document drives the generated client hooks and server Zod validators. Database: external Postgres (Neon) via DATABASE_URL, seeded idempotently on boot.
